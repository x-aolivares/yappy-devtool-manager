Sincronización entre regiones AWS

Se comparan la región de origen (izquierda, contiene los cambios nuevos) y la región destino (derecha, se actualiza). Las regiones son los ambientes definidos en config/env.* de yappy-cli-manager.

Diff de Base de Datos

Compara una tabla o un stored procedure entre dos ambientes. Si difieren te genera el script de actualización: CREATE para crear, ALTER TABLE con el diff de columnas e índices, o CREATE OR REPLACE PROCEDURE.

Diff de Parámetros / Secretos

Compara un parámetro de SSM Parameter Store o un secreto de Secrets Manager entre dos ambientes. Si el valor es JSON, actualiza solo las claves que cambiaron, sin sobreescribir el parámetro completo.

Leer Parámetros / Secretos

Pegás una lista de parámetros como JSON — [{ "key": "/path", "is_secret": false }] — y ves los valores de una. Si marcás is_secret: true los lee de Secrets Manager; el resto, de SSM.

Crear en varias regiones

Un valor, varias regiones: parámetro SSM o, marcando la opción, también secreto en Secrets Manager con el parámetro duplicado como SecureString. Genera los comandos por región o ejecútalos con tu confirmación.

Sesiones de parámetros

Pegás tu lista de parámetros desde la hoja de cálculo, elegís región de origen y destino, y vas ítem por ítem: cada uno se abre en Parámetros y el progreso queda guardado localmente para revisarlo después.

Editar un parámetro

Elegís el ambiente y ves el valor actual de un parámetro (con decodificación de SecureString), lo editás y lo guardás con tu confirmación.

Compilar / Ejecutar SQL

Elegís un ambiente y pegás el código SQL/DDL (tabla o stored procedure) para ejecutarlo directo contra esa base: ALTER / CREATE TABLE, CREATE OR REPLACE PROCEDURE, etc. Se compila y te muestra el resultado de cada sentencia.
